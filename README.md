# Glacier InfoTech portfolio

An accessible, responsive Next.js App Router portfolio site for Glacier InfoTech, built with reusable TypeScript components, Tailwind CSS, Lucide icons, and Motion.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`, or run the production server with `npm start`.

The portfolio uses the supplied `logo_round.png` and project screenshots unchanged. The four project entries use the exact deployed demo URLs supplied for Business Analytics Dashboard, CommerceHub E-commerce, Travel & Stay Booking, and Café Website.
